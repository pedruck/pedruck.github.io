PIBITI — Evolução Quantitativa de um Dashboard Open Source para Métricas e Análise de Colaboração em Projetos Acadêmicos de Software

Projeto de Iniciação Tecnológica e Inovação (PIBITI) vinculado à UnB

Ago/2026 - atual Brasília-DF · UnB

Evolução quantitativa de um dashboard open source que extrai dados de repositórios via API do GitHub e calcula KPIs de volume de atividades, revisão de código, colaboração e riscos, apresentados em visualizações interativas por organização, equipe e período.

Meu papel: iniciação tecnológica: evolução do pipeline de engenharia de dados, cálculo dos indicadores e avaliação de integração com ferramentas de gestão como Notion, Jira e Trello.

Impacto: analisa automaticamente todos os repositórios de uma org pública no GitHub, com uso validado por professores da UnB; meta de alta reprodutibilidade e testes automatizados para adoção por outras disciplinas.

  • D3.js

SeamWork — Pipeline de Testabilidade com Agentes de IA

Projeto open source nascido no hackathon do IBM TechXchange 2026. Pipeline construído sobre o IBM Bob em que agentes de IA detectam barreiras de testabilidade em pull requests e geram os testes automaticamente, com rastreamento no IBM Cloudant.

Meu papel: planejamento da arquitetura do projeto e construção de skills e orquestradores para os agentes de IA (geração de testes, análise de suítes de teste, heurísticas de testabilidade e revisão de PRs).

Impacto: overhead de apenas 4,4% de mudança em produção para tornar o código testável (32 linhas de produção para 729 linhas de funcionalidade).

  • IBM Bob
  • Agentes de IA
  • TypeScript
  • IBM Cloudant
  • GitHub Actions
